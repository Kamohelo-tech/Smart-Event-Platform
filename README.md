# 🎟️Smart-Event-Platform

A web app for browsing, managing, and booking events. Users can register, book tickets, and manage their bookings. Admins can create, edit, and delete events via a protected dashboard.
Tech Stack
Node.js · Express 5 · MongoDB (Mongoose) · EJS · bcrypt · express-session
Features

Register/login with hashed passwords and session-based auth
Role-based access (User / Admin) enforced at the route level
Browse upcoming events by category
Book tickets with capacity validation (max 20 per booking)
Cancel bookings — tickets are automatically restored
Admin dashboard for full event and booking management
Contact form with enquiry storage
